Research

AI systems increasingly make choices on a person's behalf that the person never spelled out. My approach is to make what the person wants explicit, as rules, a profile, or saved context, so the AI works within it and the person can check and change it.

Each system below has a demo you can try in the browser.

Specify

U-Define

People state their own constraints in natural language and mark each one as hard or soft. Hard rules are checked with model checking, and soft preferences are rated by an LLM judge.

Try the demoPaper

Communication Initialization Profile (CIP)

A 16-item profile that gives an LLM a starting point for how to communicate with someone before it has any history with them.

Try the demo

Check

VeriPlan

Checks an LLM's plan against rules the user confirms, using model checking, and sends any violations back to the user and the LLM.

Try the demoPaper

Revise

PromptPath

Keeps a persistent profile of the user and uses it to repair short prompts, showing which words came from the prompt, the profile, or the AI.
